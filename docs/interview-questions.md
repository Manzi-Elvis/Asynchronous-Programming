# Interview Questions

```
Junior
├── What is a Promise?
├── What are its states?
└── What does await do?

Mid-level
├── Explain Promise chaining.
├── Promise.all vs Promise.allSettled?
├── Why does forEach not work with async/await?
└── Sequential vs concurrent execution?

Senior
├── Explain the Promise resolution procedure.
├── Explain microtasks vs tasks.
├── Implement Promise.all().
├── Implement a concurrency limiter.
└── Implement a Promise pool.

Staff
├── Design a production-grade async job processor.
├── How would you implement cancellation?
├── How would you combine rate limiting and concurrency limiting?
├── How would you prevent starvation?
├── How would you handle retries?
└── How would you guarantee result ordering?
